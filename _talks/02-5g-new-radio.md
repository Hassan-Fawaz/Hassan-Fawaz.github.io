<div style="text-align: justify;">
At Télécom SudParis (IP Paris), I worked on 5G New Radio systems until 2024. The work combined system-level simulation using the ns-3-based LENA NR module with state-of-the-art 5G emulators such as Open5GS and UERANSIM, supporting the design and evaluation of 5G network architectures and mechanisms.
</div>

<div style="text-align: justify;">
Leveraging these tools allowed end-to-end studies of the 5G stack — from the core network to the radio access network — with reproducible, large-scale scenarios that would be costly or impossible to run on production testbeds.
</div>
